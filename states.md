# Estado Atual do Sistema

## Stack Tecnológica
- Monorepo de portal web com backend Java 17/Spring Boot 3.2.5 e frontend React 19/TypeScript/Vite.
- Backend: Spring Web, Spring Security, Spring Data JPA, Spring Data LDAP, Bean Validation, Actuator, Flyway, Flyway SQL Server, spring-dotenv, JJWT, Apache POI, BouncyCastle/Argon2, Microsoft JDBC Driver e H2 em testes.

- Fonte analítica externa: SQL Server `ETL_SISTEMA`/`esl_cloud`, consumido em leitura por views, fatos e synonyms publicados pelo ETL.
- Operação Windows por `iniciar-dev.bat`, `iniciar-prod.bat`, Maven Wrapper, scripts em `scripts/` e migrations em `database/`.

## Fluxo de Dados e Integrações
- Presença diária: `usePresencaNavegacao` → `PUT /api/sessao/presenca` → `NavegacaoDiaService` → `NavegacaoDiaSqlRepository` → `acesso.usuario_navegacao_dia`. Rota conhecida, foco/visibilidade e fluxo são enviados sem filtros ou conteúdo; identidade e horários vêm do servidor. Pulsos de 30 segundos confirmam permanência; SQL soma somente intervalos contínuos de até 75 segundos. `GET /api/admin/acesso/usuarios/{usuarioId}/navegacao-dia` oferece o dia de Brasília, ordem decrescente e dez páginas agrupadas por consulta, somando todos os trechos da rota no SQL antes da paginação ao operador supremo. A V069 e o baseline V001 mantêm uma linha transitória por pessoa, reutilizada; limpeza à meia-noite e no startup zera o conteúdo expirado com UPDATE, sem histórico de dias anteriores na consulta nem exclusão física de auditoria.
- Medição individual dos 19 gráficos em 60 carregamentos consolidados e quatro smokes: Faturamento terminou os desenhos 17,3% antes no desktop e 12,7% antes em CPU 4x/2 Mbps. - O resumo e histórico de comprovantes exibem `origemComprovantes`, com cliente e origem filtrando os cartões e o histórico; o resultado filtra somente as execuções históricas. ## Regras de Negócio Consolidadas
- A sessão isola o cache frontend por identidade, papel, setor, permissões, filiais e exigência de troca de senha. Alterações nesse escopo limpam queries/mutações e remontam os consumidores; uma resposta antiga não repovoa o cache após a troca. Renovação de validade sem mudança de acesso preserva os dados. O histórico de Performance inclui parceiros logísticos na chave de cache.
- Textos externos interpolados em HTML de tooltip passam por `escapeHtml`; markup fixo e marcadores ECharts são preservados, sem mudar rótulos Canvas ou valores de filtros. Três testes reproduziram injeção de elementos antes da correção.
- O isolamento DEV combina profiles ativos e marcadores de ambiente. `SqlServerJdbcUrl` interpreta localmente propriedades escapadas e recusa banco ausente, sintaxe inválida e definições duplicadas; nomes de produção dentro de chaves não contornam mais o bloqueio. O parser não abre conexão nem registra URLs.
- Autorização usa `PermissaoResolverService.resolverAcesso`/`AcessoResolvidoDTO` para reaproveitar o papel resolvido na chamada: o fluxo comum de `authoritiesFor` passou de quatro para uma invocação ao repositório de papéis. Sessão e authorities preservam a matriz ACL, com revogação relida na próxima requisição e sem cache entre chamadas.
- `AutorizacaoQueryCountTest` simula as duas leituras da revogação com `thenAnswer` e listas tipadas, sem criar array genérico para varargs; o cenário e a contagem de duas consultas permanecem iguais.
- JSON malformado, ausente ou com tipo incompatível agora retorna HTTP 400 por `HttpMessageNotReadableException`, com mensagem genérica e sem registrar o payload do parser. Quatro casos MVC reproduziram HTTP 500 antes da correção e passaram após o tratamento.
